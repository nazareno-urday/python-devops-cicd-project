# Python for DevOps: CI/CD for Python Projects

A Python project with an automated CI/CD pipeline built with **GitHub Actions**, covering code quality, testing, packaging, and publishing.

## Completed Features

- [x] Implement the Python application.
- [x] Configure and validate a GitHub Actions workflow.
- [x] Enforce linting with **Ruff** and formatting with **Black**.
- [x] Check type annotations with **mypy**.
- [x] Scan for common security issues with **Bandit**.
- [x] Automate tests with **pytest**.
- [x] Build Python distribution packages: **wheel** and **source archive**.
- [x] Publish packages to **TestPyPI** and **PyPI** when a new GitHub release is published.

## Purpose

This repository provides a practical foundation for applying CI/CD to future Python projects: automating checks, building installable packages, and delivering releases through a repeatable workflow.
